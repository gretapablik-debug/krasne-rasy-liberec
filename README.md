# Krásné řasy Liberec

Лендинг лэшмейкера в Либерце: https://krasnerasy.online

Три языка — по странице на каждый, собираются из одного шаблона. Готовые файлы
лежат в репозитории, Cloudflare Pages отдаёт их как есть, без своей сборки.

| Язык | Адрес | Файл |
| --- | --- | --- |
| Русский | `/` | `index.html` |
| Українська | `/uk/` | `uk/index.html` |
| Čeština | `/cs/` | `cs/index.html` |

## Что внутри

```
src/template.html   разметка-источник; правится только она
src/i18n.js         тексты трёх языков; в браузер не попадает
build.mjs           рендерит три страницы и sitemap.xml
index.html          \
uk/index.html        > сгенерированы, редактировать вручную бессмысленно
cs/index.html       /
sitemap.xml         /
404.html            своя страница ошибки
_headers            заголовки кэша и безопасности для Cloudflare Pages
assets/styles.css   стили и вся анимация
assets/app.js       появление блоков и плавная прокрутка
assets/*.webp       фото работ, отзывы, портрет (сжаты из PNG: 16 МБ → 0,76 МБ)
assets/og-*.jpg     превью для мессенджеров, по одному на язык
check-responsive.mjs прогон по ширинам телефонов
```

## Как вносить правки

```bash
npm install      # один раз
npm run build    # после любой правки src/
npm run check    # прогон по ширинам телефонов
```

Сборка перезаписывает `index.html`, `uk/index.html`, `cs/index.html` и
`sitemap.xml`. Коммитить нужно и источник, и результат — Cloudflare ничего не
собирает сам.

Текст меняется в `src/i18n.js`: это один объект на язык, разметку трогать не
нужно. Структура страницы — в `src/template.html`, там же `data-t` крючки,
по которым сборка расставляет переводы.

Посмотреть локально:

```bash
npm run serve    # http://localhost:8080
```

Открывать именно через сервер: пути к файлам начинаются со слэша, и по
`file://` они не найдутся.

## Почему страницы отдельные, а не переключение в браузере

Поисковик видит только то, что пришло в HTML. Пока язык переключался скриптом,
чешский и украинский тексты не индексировались вообще — то есть сайт был
невидим на том рынке, который для мастера в Либерце основной. Теперь у каждого
языка свой адрес, свои `canonical` и `hreflang`, а переключатель — обычные
ссылки, по которым робот проходит.

## Микроразметка

Сборка добавляет на каждую страницу `BeautySalon` (телефон, город, цены шести
услуг) и `FAQPage` (пять вопросов из блока на странице) на языке этой страницы.
Проверить после деплоя: [Rich Results Test](https://search.google.com/test/rich-results).

## Проверка адаптивности

`npm run check` открывает все три страницы в восьми размерах — от Galaxy Fold
в сложенном виде (280px) до планшета — и ищет две вещи: что-нибудь, вылезающее
за ширину экрана, и кнопки или ссылки ниже 44px. Сайт должен запускаться
локально (`npm run serve`), проверка стучится на `http://127.0.0.1:8080`.

Проверка умеет отличать настоящую мелкую кнопку от такой, у которой зона
касания расширена псевдоэлементом, — она щупает точки через
`elementFromPoint`, а не меряет рамку.

## Анимации

Анимируются только `opacity` и `transform` — такие кадры считает композитор, и
страница держит 120 Гц. Длительности намеренно долгие (0,9–1,4 с) на кривой
`cubic-bezier(0.16, 1, 0.3, 1)`, соседние блоки появляются со сдвигом.

Скрытое состояние привязано к классу `anim`, который ставит инлайн-скрипт в
`<head>`. Нет JavaScript — класса нет, и страница просто видна целиком. При
`prefers-reduced-motion: reduce` вся анимация отключается.

Направление входа повторяет вёрстку: левая колонка приезжает слева, фото
рядом — справа. Фотографии идут дольше остальных блоков и выходят из лёгкого
зума. Заголовки поднимаются из-за собственной рамки: `<h1>`/`<h2>` работают
маской, двигается вложенный `<span class="rise">`, который расставляет сборка.
Отступ сверху и снизу у маски — чтобы чешские `ř` и `ů` не срезало.

Галереи работ и отзывов используют скролл-привязанную анимацию
(`animation-timeline: view()`): браузер считает её на потоке композитора, без
единого обработчика прокрутки. Где не поддерживается — картинки просто стоят.

Список появляющихся блоков продублирован в двух местах: `REVEAL_SELECTOR` в
`assets/app.js` и блок `.anim` в `assets/styles.css`. Меняя один, поменяйте и
второй.

## Превью для мессенджеров

`assets/og-ru.jpg`, `og-uk.jpg`, `og-cs.jpg` — 1200×630, под пропорции, в
которые режут превью Telegram, WhatsApp и Facebook. Они не собираются
автоматически: карточка рисуется как HTML и снимается скриншотом браузера,
иначе не будет настоящих шрифтов. Если меняется заголовок или фото — карточки
нужно перерисовать вручную.

## Деплой

Репозиторий связан с Cloudflare Pages: push в `main` разворачивается сам.
Настройки проекта — Framework preset `None`, build command пустой, build output
directory `/`.
