# Krásné řasy Liberec

Лендинг лэшмейкера в Либерце. Статика — без сборки, без зависимостей: открывается
как `index.html` и так же разворачивается на Cloudflare Pages.

## Что внутри

```
index.html          разметка; русская версия отрендерена сразу (SEO + работа без JS)
assets/styles.css   стили и вся анимация
assets/i18n.js      тексты на трёх языках: ru / ua / cz
assets/app.js       переключение языка, появление блоков, плавная прокрутка
assets/*.webp       фото работ, отзывы, портрет (сжаты из PNG: 16 МБ → 0,76 МБ)
_headers            заголовки кэша и безопасности для Cloudflare Pages
```

## Языки

Язык берётся в таком порядке: `?lang=ru|ua|cz` в адресе → сохранённый выбор в
`localStorage` → язык браузера → русский. Тексты лежат в `assets/i18n.js`:
правка цен или описаний — это один объект на язык, разметку трогать не нужно.

Русская версия продублирована прямо в `index.html`, чтобы страница читалась
поисковиками и без JavaScript. При изменении текстов правьте оба места: словарь
в `i18n.js` и русский вариант в разметке.

## Анимации

Анимируются только `opacity` и `transform` — такие кадры считает композитор, и
страница держит 120 Гц. Длительности намеренно долгие (0,9–1,4 с) на кривой
`cubic-bezier(0.16, 1, 0.3, 1)`, появление соседних блоков идёт с задержкой.

Скрытое состояние блоков привязано к классу `anim`, который ставит инлайн-скрипт
в `<head>`. Нет JavaScript — класса нет, и страница просто видна целиком.
При `prefers-reduced-motion: reduce` вся анимация отключается.

Список блоков, которые появляются при прокрутке, продублирован в двух местах:
`REVEAL_SELECTOR` в `assets/app.js` и блок `.anim` в `assets/styles.css`.
Меняя один, поменяйте и второй.

## Локальный запуск

Файл можно открыть двойным щелчком, но лучше через сервер — иначе
`localStorage` и относительные пути ведут себя иначе, чем на хостинге:

```bash
python -m http.server 8080
# http://localhost:8080
```

## Деплой на Cloudflare Pages

Проект связан с этим репозиторием: каждый push в `main` собирает новую версию.
Настройки в Pages:

| Поле | Значение |
| --- | --- |
| Framework preset | None |
| Build command | *(пусто)* |
| Build output directory | `/` |

Либо вручную, без Git:

```bash
npx wrangler pages deploy . --project-name krasne-rasy-liberec
```

## Домен

Сайт живёт на https://krasnerasy.online — адрес прописан в `canonical`,
`og:url` и `og:image`. При переезде на другой домен замените все три в
`<head>` файла `index.html`.
